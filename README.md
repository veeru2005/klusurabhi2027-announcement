# Surabhi 2027 — single page (Vercel)

Preloader intro + the hero screen only (title, dates, countdown, logo). No navbar, buttons, footer or other pages.

## Run locally
npm install
npm run dev

## Deploy on Vercel
1. Push this folder to a new GitHub repo.
2. vercel.com → Add New → Project → import the repo.
3. Framework: Vite (auto-detected). Build command: npm run build. Output: dist.
4. Deploy.

Or with the CLI: npm i -g vercel && vercel --prod
